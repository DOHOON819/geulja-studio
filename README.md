# 글자작업실

브라우저에서만 작동하는 한국어 텍스트 검사·정리 도구. 원문을 유지하면서 결과를 비교합니다.

- 문자 묶음(한글/이모지), 공백 제외 글자수, UTF-8 바이트, 공백 기준 단어와 줄 수
- 줄 끝 공백, 연속 공백/빈 줄, 중복 줄, 일부 숨은 문자 정리와 NFC 정규화
- 클립보드 복사, UTF-8 TXT 저장, 모바일 지원
- 서버 요청·분석·광고·외부 의존성·지속 저장 없음

`npm test`로 Unicode와 정리 동작을 검증합니다. `dist/`를 정적 웹서버에서 제공합니다. 코드 포인트 계산으로 대체하는 구형 브라우저에서는 안내 메시지가 나타납니다.

특정 지원서 시스템의 자체 글자수·바이트 기준을 보장하지 않습니다. 아직 광고·결제 연결이 없으며 수익화가 완료된 제품이 아닙니다.
